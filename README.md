# Design → HTML（设计稿还原 Skill）

将第三方提供的设计图（PNG / JPG / Figma / Sketch，1~N 张）系统性还原为开发可用的 HTML 文件，还原度目标 ≥ 90%。

本仓库是 **WorkBuddy Skill** 的源文件，对应在 WorkBuddy 中的安装路径为 `~/.workbuddy/skills/设计还原/`。

---

## 仓库内容

```
design-to-html/
├── SKILL.md                       # 主文件：流程编排 + 决策规则（10 个模块）

```

## 适用场景

- 第三方一次性给 1 张 / 几张 / 几十张设计图
- 目标是"高保真还原"为可开发 HTML / 页面 / 组件
- 输入既可能是整张位图（PNG/JPG），也可能是分层源文件（Figma / Sketch / PSD）

---

## 核心方法

- **标注先行**：还原质量在「解析 / 拆解 / 标注」阶段就已决定，HTML/CSS 只是机械翻译
- **一图一档**：每个页面产出独立的「视觉拆解单」，作为该页唯一作业依据
- **门槛放行**：六个阶段各设质量门槛（G0–G5），不达标回退，禁止带病进入下一阶段
- **素材分层**：SVG 只承接可被路径描述的规则几何；手写字 / 水彩 / 纹理 / 摄影一律用位图，不强行转 SVG

---

## 六步流水线

```
Step1 收集盘点 ──G0──▶ Step2 全局定标 ──G1──▶ Step3 单页拆解 ──G2──▶
Step4 结构搭建 ──G3──▶ Step5 样式还原 ──G4──▶ Step6 还原验收 ──G5──▶ 交付
```

| 阶段 | 关键产出 | 模板 |
|---|---|---|
| Step 1 收集盘点 | 设计稿清单 | T5 |
| Step 2 全局定标 | 全局设计标准文档 | T1 |
| Step 3 单页拆解 | 单页视觉拆解单 + SVG/位图素材 | T2 / T3 |
| Step 4 结构搭建 | HTML 结构草案 | T7 |
| Step 5 样式还原 | 前端代码规范 | T8 |
| Step 6 还原验收 | 还原度评分表 + 问题修复清单 | T4 / T6 |

详细字段结构见 [`references/templates.md`](./references/templates.md)。

## 还原度量化标准

| 维度 | 权重 | 红线 |
|---|---|---|
| 布局与尺寸 | 30% | 单项 ≥ 90% |
| 色彩 | 20% | 单项 ≥ 90% |
| 字体排版 | 20% | — |
| 素材质量 | 15% | — |
| 交互状态 | 10% | — |
| 响应式 | 5% | — |

**综合 ≥ 90 分且布局/色彩单项不破红线** = 验收通过。

---

## 规模适配

| 输入规模 | 全局标准 | 执行模式 |
|---|---|---|
| 1 张 | 轻量，直接进单页 | Step1→6 顺序走一遍 |
| 2–5 张 | 简版 | Step2 简版标准，Step3–6 逐页循环 |
| 6+ 张 | 完整版，先做 | Step2 做一次，Step3–6 多页并行 |
