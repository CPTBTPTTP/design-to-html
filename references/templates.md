## T3 SVG/位图素材整理规范

### 3.1 素材格式判定

按 SKILL.md「素材格式判定决策树」执行，判定结果落到素材清单。

### 3.2 导出设置

| 项目 | 规范 |
|---|---|
| 文字 | 全部转轮廓 |
| 描边 | 转轮廓，避免缩放失真 |
| viewBox | 保留，不得裁剪 |
| 精度 | 保留 1–2 位小数 |
| 尺寸 | 按设计稿原始尺寸 |
| 背景 | 透明背景导出 |

### 3.3 命名规范

`{类型}-{名称}-{序号}.svg/png/webp`

| 前缀 | 含义 |
|---|---|
| `icon-` | 图标 |
| `illus-` | 插画 |
| `decor-` | 装饰图形 |
| `bg-` | 背景/纹理 |
| `logo-` | Logo |
| `text-` | 转轮廓的静态文字 |

### 3.4 目录结构

```
assets/svg/       # 图标、Logo、规则图形
assets/img/       # 手写字、水彩、纹理、摄影
```

### 3.5 导出后优化与质量检查清单

- [ ] 文字已转轮廓，无字体依赖
- [ ] 描边已转轮廓
- [ ] viewBox 正确，无裁剪
- [ ] 背景透明
- [ ] 命名符合规范
- [ ] 已压缩优化（SVGO / 图片压缩）
- [ ] 尺寸与设计稿一致

## T4 还原度评分表

**用途**：Step6 验收的核心量化工具，逐项打分。

| 维度 | 子项 | 权重 | 评分规则（满分100，逐项扣分） |
|---|---|---|---|
| 布局与尺寸(30%) | 区块位置 | 10 | 偏移 >2px，每处 −5 |
| | 元素尺寸 | 8 | 误差 >2px，每处 −5 |
| | 间距 | 6 | 误差 >2px，每处 −3 |
| | 对齐 | 6 | 未对齐，每处 −3 |
| 色彩(20%) | 色值匹配 | 12 | 色值不符，每处 −5 |
| | 渐变/透明度 | 8 | 不符，每处 −4 |
| 字体排版(20%) | 字体族 | 5 | 不符，每处 −5 |
| | 字号/字重 | 7 | 不符，每处 −3 |
| | 行高/字距 | 8 | 不符，每处 −2 |
| 素材质量(15%) | 图标清晰度 | 5 | 模糊/锯齿，每处 −3 |
| | 图片比例/无拉伸 | 10 | 变形，每处 −5 |
| 交互状态(10%) | hover/点击/禁用 | 5 | 缺状态，每处 −2 |
| | 动效还原 | 5 | 缺失/偏差，每处 −2 |
| 响应式(5%) | 各断点布局 | 5 | 错乱，每断点 −2 |

**结论判定**：综合得分 = Σ(子项得分 × 权重)，≥90 分达标；布局、色彩两维度单项加权后不得低于各自满分的 90%（红线项）。

## T8 前端代码规范

| 项 | 规范 |
|---|---|
| 样式组织 | 色值/字号/间距必须用 CSS 变量，禁止硬编码 |
| 变量来源 | 一律取自 T1 全局标准文档的 Token 名 |
| 类命名 | BEM：`block__element--modifier` |
| 布局 | 优先 Flex/Grid，不用定位硬凑 |
| 响应式 | 移动优先，媒体查询按 T1 断点 |
| 注释 | 每个区块标注对应拆解单区块编号 |
| 素材引用 | SVG/位图按 T3 命名与目录，禁止临时命名 |
