# 素材提取与登记

高还原度依赖正确的素材边界，而不是把所有差异都交给 CSS 或把整页做成截图。

## 分类决策

| 元素 | 默认实现 |
|---|---|
| 纯色、边框、规则圆角、简单渐变 | CSS |
| 有可靠源文件的图标、Logo、规则图形 | SVG，保留 `viewBox` |
| 静态品牌字、手写寄语、复杂装饰字 | SVG 或透明 PNG/WebP，取决于源文件可信度 |
| 摄影、插画、水彩、纸纹、复杂滤镜 | PNG/WebP；透明内容使用透明底 |
| 可变业务文字、数字、状态、按钮文案 | DOM |

“看起来不需要交互”不是唯一依据；元素还必须稳定、不会随数据变化，并且使用图片不会破坏访问、定位或维护需求。

## 裁切与处理

对来自整张设计图的裁图，在 T3 记录源文件、原始坐标、导出比例、最终尺寸和用途。检查并处理白边、背景残留、投影截断、半透明锯齿和色彩偏移；保留原始裁图或可重放的坐标，避免下一次只能手工重裁。

不要把普通截图临摹成“原始 SVG”，也不要为了追求矢量而损失笔触、纹理或透明效果。无法可靠分离时，说明限制并使用可接受替代方案。

## 命名与目录

使用能定位页面和语义的路径，例如：

```text
assets/
  shared/logo-*.svg
  shared/icon-*.svg
  pages/07-home/decor-note.webp
  pages/07-home/illus-checklist.png
```

T3 是素材的唯一登记表：包含来源、裁切、处理方式、用途与风险。不要在 T1、T2 和 README 复制同一素材说明。
