# 项目配置与金样映射

在写 HTML、抽取 Token 或裁切素材前建立 P0。P0 是本次还原的测量基准，不是通用设计规范。

## 画布选择

优先使用提供设计图的实际画布。将“设计稿导出像素”与“实现 CSS 像素”区分开：若它们不同，记录缩放比例并用同一比例量取所有尺寸。不要仅凭设计图很像手机界面，就默认使用 390px。

| 场景 | P0 应记录的基准 |
|---|---|
| 单一移动端界面 | 设计基准 CSS 宽高、DPR、固定画布或移动响应策略 |
| 多断点网页/H5 | 每个已提供断点的 CSS 宽高、金样文件与对应状态 |
| 固定宣传页/专题页 | 桌面和移动金样分别记录；未提供的断点是实现假设 |
| 固定版式/画册 | 页面尺寸、比例、出血/安全区和最终 HTML/PDF 输出方式 |
| 大屏 | 逻辑画布、等比缩放规则、实际展示分辨率 |

## 金样映射要求

每张金样必须有唯一的“文件 → 页面/路由 → 状态/数据 → 基准画布”记录。一个页面多个状态应拆开登记，不能以同一个默认页替代空态、已完成态或弹层态。

金样更新后提升版本号或更新时间，并明确旧金样是否失效。若视觉稿和现有代码冲突，以用户确认的金样版本为准；不确定时停在 G0 询问。

## 截图配置

截图工具由项目自行选择，但必须能：

1. 设定 P0 的 CSS 视口与 DPR；
2. 截图前读取并记录 `window.innerWidth`、`window.innerHeight` 和 `devicePixelRatio`；
3. 等待页面和字体加载完成；
4. 设定与金样一致的滚动位置、数据和控件状态；
5. 将当前截图、对比图和差异记录写到稳定目录。

浏览器窗口外框大小、操作系统缩放或截图位图尺寸都不足以证明 CSS 视口正确。
